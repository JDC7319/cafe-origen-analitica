# cafe-origen-analitica

## Descripción
Proyecto desarrollado en JavaScript y Node.js para analizar el historial de ventas de Café Origen, una tostadora de café de especialidad de Medellín.

## Objetivo
Construir un motor de analítica que permita responder preguntas de negocio utilizando arreglos, objetos, ciclos y funciones de JavaScript.

## Tecnologías
- JavaScript
- Node.js
- Git y GitHub

## Estructura del proyecto
- `src/datos.js`: historial de ventas.
- `src/explorar.js`: exploración inicial de los registros.
- `src/analitica.js`: funciones de análisis que se desarrollarán en los siguientes retos.
- `bitacora.md`: documentación del proceso, pruebas y decisiones.

## Ejecución
Desde la raíz del proyecto:

```bash
node src/explorar.js
```

## MiniReto 1
Se modelaron 12 registros de ventas y se identificaron casos borde relacionados con ciudades, cantidades y clientes.
